# A04 보고서 초안 작성 Agent

> 근거: `Agent정의서_4_보고서초안작성.docx` · 앞 Agent: A03 목적별 자료 추출

| 구분 | 내용 |
|---|---|
| 목적 | A03 자료표와 담당자가 고른 양식으로 보고서 초안을 쓰고, 수치·출처·필수 항목을 스스로 점검한다 |
| 시작 조건 | 담당자가 보고서 양식(보고 유형·목차·회사 양식)을 고르고 A03 자료표가 준비되었을 때 ("보고서 초안 만들기") |
| 입력 | ① A03 자료표 ② 보고서 양식(목차·필수 항목, 회사 양식 HWPX/DOCX) ③ 수정 의견(목차별 직접 입력 줄) |
| 출력 | 보고서 초안: 한글(hwpx)·워드(docx)·화면 미리보기 + **자동 점검 결과** |
| 사람 개입 | **담당자 최종 검토(필수)**. 고칠 점이 있으면 목차·직접 입력 줄을 고쳐 다시 만든다. 대외용은 출처 원문을 직접 확인한다 |
| 도구 | 양식 읽기(회사 한글 서식 복제), AI 언어모델(키 있을 때 '종합 의견' 문장만, 숫자는 만들지 않음), 점검 규칙(수치 대조), 문서 저장 |

## 수행 단계와 코드
| 단계 | 하는 일 | 코드 |
|---|---|---|
| ① | 양식의 목차·필수 항목 파악 | `draft.PRESETS`(보고 유형별 기본 목차), `draft.SECTIONS`, 회사 양식 `lh_style.FORMS` |
| ② | 자료표 값을 목차 위치에 배치 | `agent.run` → `draft.build` |
| ③ | 문장 작성(자료표에 없는 수치 금지, 미확정은 "확인 필요") | `draft.build` (+ AI 종합 의견 `draft.llm_opinion`) |
| ④ | **자동 점검** | `agent.check` |
| ⑤ | 저장(내려받기), 담당자 검토 요청 | `agent.Layout` → `.hwpx()` `.docx()` `.html()` |
| ⑥ | 반려 시 수정 의견 반영해 다시 작성 | 화면에서 목차·직접 입력 수정 → 다시 `agent.run` |

## 자동 점검 (`agent.check`) — 4가지
| 점검 | 통과 기준 |
|---|---|
| 수치 대조 | 초안의 "숫자+단위"(억원·km·차로·㎡)가 모두 자료표 값, 문서 이력 값, 같은 항목끼리 더한 합계 중 하나와 같음 |
| 출처 | 자료표의 값마다 근거 문서(문서ID·위치)가 있음 |
| 필수 항목(목차) | 고른 목차가 초안에 모두 있음 |
| 미확정 표시 | A03의 부족·미확정 항목이 초안에 "확인 필요/미확정"으로 드러남 |
- `selftest.py` 10번 시험은 일부러 틀린 수치를 넣거나 목차를 빼고, 점검이 그것을 잡아내는지 확인합니다.

## 입구 함수 (`agent.py`)
```python
from agents.a04_draft import agent as A04
tail, sections = A04.PRESETS['현안사항 보고']
blocks = A04.run(a03_result, cands, sources, choices, title, district, dept, sections, extra={})
checks = A04.check(blocks, a03_result, cands, sections)        # [{'점검','결과','설명'}]
lay = A04.Layout(blocks, '짧은 보고서(푸른색)', a03_result['facts'], district)
lay.hwpx(); lay.docx(); lay.html()
```

## 회사 양식
- 회사 권장양식 한글 서식 파일은 `templates/company/`에 둡니다. **공개 저장소에는 올리지 않습니다(.gitignore).**
- 서식 파일이 없으면 워드에만 회사 양식이 적용되고, 한글본은 기본 서식(`templates/report_template.hwpx`, 합성 서식)으로 나옵니다.
- 한글 표 규칙: 본문 칸은 한 줄(필요하면 11pt까지 줄임), 선은 모두 검은색, 제목줄 아래만 이중선.

## 정의서와 다른 점 (현재 구현)
- AI는 '종합 의견' 문장만 씁니다. 본문 문장은 정해진 개조식 틀에 DB 값을 넣어 만듭니다. 그래서 숫자가 틀릴 수 없습니다.
- 반려 후 다시 쓰기는 담당자가 화면에서 목차·직접 입력을 고쳐 "다시 만들기"를 누르는 방식입니다. 수정 의견 문장을 AI가 읽어 자동 반영하지는 않습니다.

## 파일
- `agent.py` 입구·자동 점검·양식 적용 · `draft.py` 초안 블록, 기본 한글·워드 · `lh_style.py` 회사 양식 규칙(미리보기·워드) · `hwpx_forms.py` 회사 한글 서식에 채우기
